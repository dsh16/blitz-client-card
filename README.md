# Blitz — карточка клиента

Страница на Nuxt 2.18.1 и Vue 2.7.16 по предоставленному макету.

```sh
npm ci
npm run dev
```

Для production: `npm run build`, затем `npm start`. Сервер использует порт 3000.
В облачной среде перед установкой задайте доступный кэш:
`export npm_config_cache=/workspace/.cloud-setup/npm-cache`.

Работают редактирование контактов и данных автомобиля, теги, оформление абонементов, создание и отмена записей, чёрный список, поиск клиента и экспорт JSON. Данные сохраняются в `localStorage` текущего браузера. Это интерфейс без серверной базы данных и авторизации.

Страница адаптирована для мобильных экранов; таблица посещений прокручивается горизонтально. Иконки — локальные SVG, внешние шрифты и изображения не требуются.

## GitHub Pages

Workflow `.github/workflows/deploy-pages.yml` публикует статическую версию при изменениях в `main`. В настройках репозитория **Settings → Pages → Build and deployment → Source** должен быть выбран **GitHub Actions**.

Адрес после успешного деплоя: https://dsh16.github.io/blitz-client-card/.

Локальная сборка статической версии с тем же префиксом путей:

```sh
NUXT_DEPLOY_TARGET=static NUXT_ROUTER_BASE=/blitz-client-card/ npm run generate
```

Содержимое `dist/` можно разместить на статическом хостинге. Для локальной разработки префикс не нужен: `npm run dev` работает как прежде.
